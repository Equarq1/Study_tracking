# Study Tracking

Study Tracking — веб-платформа для учета и оценки достижений студентов.

Проект позволяет вести цифровое портфолио, в котором сохраняются учебные и внеучебные достижения. Студент может отправить заявку с описанием своего достижения, после чего система предлагает количество XP, а преподаватель или куратор проверяет заявку и подтверждает ее.

## Возможности

- регистрация и авторизация пользователей;
- REST API;
- JWT-аутентификация;
- работа с достижениями студентов;
- PostgreSQL;
- взаимодействие с клиентской частью через API.

## Технологии

- Python
- Django
- Django REST Framework
- PostgreSQL
- Simple JWT

## Запуск проекта

```bash
git clone https://github.com/Equarq1/Study_tracking.git
cd Study_tracking

python -m venv venv

# Windows
venv\Scripts\activate

# Linux/macOS
source venv/bin/activate

pip install -r requirements.txt

python manage.py migrate
python manage.py runserver
```
